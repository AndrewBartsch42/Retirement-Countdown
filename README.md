# Retirement-Countdown
AUTHORS: ![Andrew Bartsch](https://github.com/AndrewBartsch42)  ![Kaleb Aregay](https://github.com/Kalebk24)  
  
PROGRAM DESCRIPTION:  
This program is a website that calculates the investment quantity of an initial investment over a period of time. This is done for the use of a retirement countdown to view how much money based on a fixed interest rate that a person would have at the end of a given time period. The program also adjusts for a fixed monthly contribution to the retirement or investment fund.  
  
NEW CONCEPTS:  
- Data validation with a try catch
- interval logic with a repeated function
- reset function for data fields and div sizing
